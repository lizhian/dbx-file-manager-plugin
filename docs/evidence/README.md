# Local acceptance evidence

Raw verification reports, screenshots and host logs are retained in the local
workspace but excluded from this public repository. They can include machine
paths and environment details that are unnecessary for building the plugin.

The parent documentation summarizes the tested inputs, artifact hashes, observed
results and remaining limitations. Historical links to files in this directory
describe that local archive and are not publicly downloadable evidence. They do
not replace independently reproducing a test against a specified candidate.

Reproduce checks using the commands in the root README and the scoped acceptance
documents. The scripts generate new reports here. Review and redact any report
before explicitly publishing it; never include credentials or private keys.
